# 🎧 Sample Meeting Audio Files

This directory contains pre-generated audio files for quick verification, testing, and live demonstration of the **AI Meeting Assistant** without requiring external recordings.

## Included Audio Files

| File Name | Format | Duration | Language | Description |
|:---|:---|:---|:---|:---|
| `sample_meeting_en.wav` | 16kHz Mono PCM WAV | ~29 seconds | English | Crystal-clear 2-person business meeting (David & Zira) discussing Q3 budget & deliverables. |
| `sample_meeting_en.mp3` | 128kbps Stereo MP3 | ~29 seconds | English | Standard MP3 format of the conversational Q3 budget review demo. |

## How to Test

1. Launch the system via `run_all.bat` or start backend + frontend.
2. Open **http://localhost:5173**.
3. Drag and drop either `sample_meeting_en.wav` or `sample_meeting_en.mp3` directly into the upload area (or click **Load Sample File** in the demo card).
4. Preview the audio using the built-in HTML5 Audio Player.
5. Click **Start Processing** to run the complete pipeline!

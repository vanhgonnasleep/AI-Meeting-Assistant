1. HƯỚNG DẪN KHỞI CHẠY 1-CLICK (QUICK START GUIDE)
================================================================================

YÊU CẦU HỆ THỐNG / PREREQUISITES:
  - Hệ điều hành: Windows 10/11, macOS hoặc Linux
  - Đã cài đặt: Node.js 18+ (khuyên dùng Node.js 20 hoặc 24 LTS)
  - Đã cài đặt: Python 3.10+ (đã tích hợp sẵn virtualenv hoặc chạy python hệ thống)

CÁCH 1: KHỞI CHẠY 1 CÚ NHẤP CHUỘT TRÊN WINDOWS (RECOMMENDED)
  1. Nháy đúp vào file `run_all.bat` (hoặc `run_clarion.bat`) ở thư mục gốc.
  2. Script sẽ tự động:
     - Kiểm tra môi trường Node.js và Python
     - Tự động cài đặt dependencies frontend nếu chưa có (`npm install`)
     - Khởi chạy Backend FastAPI tại: http://localhost:8002
     - Khởi chạy Frontend React Studio tại: http://localhost:5173
     - Tự động mở trình duyệt web đến giao diện làm việc.

CÁCH 2: CHẠY QUA DOCKER (CONTAINERIZED)
  - Chạy lệnh:
      docker-compose up --build
  - Truy cập ngay: http://localhost:5173

CÁCH 3: TRẢI NGHIỆM TỨC THÌ (DEMO SAMPLE MODE)
  - Clarion tích hợp sẵn chế độ "Instant Demo (Zero Compute)" và nút "Load Sample Audio".
  - Thầy/Cô chỉ cần bấm "Load Sample Audio" để trải nghiệm trọn vẹn toàn bộ quy trình:
    + Xem văn bản bóc băng gán nhãn người nói và mốc thời gian
    + Nghe và đồng bộ tua audio thời gian thực theo từng câu
    + Xem bản tóm tắt điều hành (Executive Summary)
    + Kiểm tra danh sách công việc (Action Deliverables)
    + Xem ma trận 3 cột (Quyết định, Rủi ro, Câu hỏi mở)
    + Trình chiếu slide thuyết trình Zen Deck

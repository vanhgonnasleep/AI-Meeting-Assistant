# Maintenance audit — 2026-10-15

Scope: current workspace specification, recent operations scripts and launcher changes,
database recovery, benchmark evidence, existing backend/frontend regression suites and
open GitHub pull requests. This is a focused maintenance audit, not an exhaustive security scan.

Acceptance criteria: [maintenance specification](superpowers/specs/2026-10-15-maintenance-audit.md).

## Findings and fixes

| Area | Observed failure | Correction |
| --- | --- | --- |
| Legacy databases | DB manager created indexes on columns missing from original schemas | Apply shared application migrations before indexes; preserve existing minutes |
| Project seeding | Fixed project IDs attached demo meetings to unrelated existing projects | Resolve project IDs from casefolded names |
| Backup and recovery | Same-second backups overwrote each other, including the selected restore input | Reserve unique backup files and close connections on errors |
| Restore validation | Self restore could block; invalid or incomplete inputs reached the live DB | Validate distinct source, SQLite integrity and original meeting columns before backing up/copying |
| Python wrapper | Global interpreter bypassed installed backend dependencies; launch errors/signals returned success | Prefer backend venv and propagate failure |
| Windows launcher | Relative venv path broke after changing directory; stale ERRORLEVEL expansion and npm batch invocation broke fallback/install flow | Resolve interpreter path first, evaluate errorlevel at execution, call npm and stop on installation failure |
| Benchmark inference | Missing FFmpeg on PATH prevented inference despite bundled decoder availability | Decode through existing PreparedAudio and measure CPU inference on PCM |
| Benchmark evidence | Failed Whisper runs substituted fixed timing numbers; sequential SQLite results were described as concurrency evidence | Report skipped measurements explicitly, use measured duration and aggregate write throughput, state fixture/workload limits |

Independent review found two additional cases during implementation: incomplete restore
schemas and malformed benchmark WAV files. Both have regression tests and fixes.

## Verification

- Eleven operations regressions and three Node wrapper regressions reproduced failures
  before fixes and pass after fixes. All DB writes in these tests use temporary files.
- Full backend command: `ai-summary-service/venv/Scripts/python.exe -m pytest ai-summary-service/tests -q --run-model-tests`.
  Result: 235 passed, including real Whisper integration; two existing dependency deprecations.
- Frontend command sequence: `npm test`, `npm run lint`, `npm run build`, `npm audit --omit=dev`.
  Frontend and wrapper tests: 80 passed. Production dependency audit: zero vulnerabilities.
- Benchmark report regenerated by the backend venv with actual Whisper inference. Measurements
  are machine/workload specific; see [the report](BENCHMARK_REPORT.md).
- Independent read-only review approved integration after both findings were resolved.
- GitHub REST API returned no open pull requests during this audit; there was no existing PR to merge.

Limits: Windows service windows were not launched; launcher path resolution was inspected
and its resolved interpreter invoked from the backend directory. Existing backend dependency
deprecations and frontend bundle-size warning remain. No production meeting content was read,
seeded, cleaned or restored during this audit. Remote CI status is checked after publishing.
